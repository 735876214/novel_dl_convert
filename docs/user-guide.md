# 使用说明（user-guide）

> 面向**使用者**：每个功能是干什么的、在哪儿、怎么用、有哪些边界。
> 部署与配置见 `README.md`；原理见 `docs/architecture.md`；界面视觉规范见 `DESIGN.md`。

## 1. 第一次进入

1. 浏览器打开 `http://<NAS-IP>:8992`（默认端口；部署细节见 `README.md`）。
2. 登录：字段是 **账号 + PIN**（默认 `admin` / `changeme`，请尽快在「设置 → 你 → 个人资料」改）。
3. 若还没有书库，会看到**首屏引导**：点「新增书库」打开**就地弹窗向导**（5 步：基本信息 → 来源 → 扫描 → 阅读 → 自动化）。
   - **来源**必须落在「来源根」之内（部署时的 `LIBRARY_SOURCE_DIR` 或其下的多根 `LIBRARY_SOURCE_DIRS1..N`）。
   - 也可以稍后在 **设置 → 书库 → 书库管理**（`#/settings/libraries`）里管理。
4. 建库后再点「立即扫描」，书就进书架了。

> 顶栏是**全站入口行**（仪表盘 / 探索发现 / 收书目录 / 数据统计 / 阅读记录 / 通知 / 成就 / 任务 / 工具 / 搜索 / 外观 / 用户菜单）；
> 左侧栏负责**浏览类**导航（实体总览 / 作者 / 系列 / 批注 + 库 / 智能书架 / 收藏夹 / 帮助）。

## 2. 把书放进去（三条路）

| 方式 | 怎么做 | 结果 |
|---|---|---|
| **丢文件** | 把文件拷进部署目录的 `./input` | 自动收进书库并记日志（`.txt` **原样入库**，不再转换） |
| **界面导入** | 工具 → 本地导入：拖拽上传 / 按服务器路径入库；也可启停监听、立即扫描 | 同上 |
| **在线书源** | 探索发现：搜书名 → 结果可「预览」→「下载」；进度在任务中心 | 抓到正文 → 分章 → 组装 EPUB → 入库 |

支持形态：EPUB / PDF / TXT / FB2 / MOBI / AZW3…、漫画 CBZ / CBR、有声书（单文件或**一章一文件的目录**）。
`.cbr` 需要容器内有 `bsdtar`（官方镜像已含）；未安装时相关入口会明确提示。
**放进书库根目录**的还有第三种形态：漫画库 / 有声书库里的**序号单元树**（`《书名》/第1卷/第1话.pdf`…）
—— 一棵树会合成**一本书**、逐话连续读（见 §4）。⚠️ 走「收书目录」丢进来的目录**不做**这种合并。

## 3. 找书与分类

- **书架**（顶栏「书架」）：网格 / 列表 / 表格三视图；搜索、排序、按系列折叠、多选批量（标记状态 / 评分 / 加入收藏夹）；
  首字母分桶跳转；书卡上有 ⋮ 菜单（阅读/收听、快速预览、下载、详情、删除）。
- **实体总览**（侧栏「浏览 → 实体总览」）：按**本地**元数据维度浏览（作者 / 系列 / 题材 / 出版社 / 语言 / 收藏六维）。
  ⚠️ 与「探索发现」不是一回事：那是**外部书源检索**。
- **智能书架**（侧栏）：自定义规则（字段 + 操作 + 值；全部满足 / 任一满足），规则存服务端、命中数实时预览。
- **收藏夹**（侧栏）：跨书归类，可新建 / 加书 / 移出 / 重命名。

## 4. 读书

| 阅读器 | 入口 | 主要设置 |
|---|---|---|
| **ePub / TXT** | 书卡或详情页「阅读」 | 排版增强：翻页/纵向/横向、分栏、字距词距、两端对齐、13 档主题、字体/字号/行高/宽度/边距/缩进；**滚动到底自动续下一章**（默认开） |
| **PDF** | 同上（PDF 走 pdf.js） | 滚动模式（翻页/纵向/横向）、页展（单/双页奇右/偶右/自动）、适配（整页/宽度/自动/自定义）；**读完自动进下一册**（默认开） |
| **漫画（CBZ/CBR）** | 同上 | 模式（翻页/纵向/无间隙）、单双页、适配、方向（左→右 / 右→左）、页间距、背景、跨页对齐、宽页处理、小屏强制双页、**自动翻下一册**（默认开） |
| **有声书** | 书卡或详情页「收听」 | 倍速、快退/快进间隔、睡眠定时、轨列表；**同册内自动续下一轨**（内置）+ **跨册续接**（默认开） |
| **合集（话）** | 书卡或详情页「阅读」（漫画库 / 有声书库里的序号单元树，见 §2） | 左边话目录 + 上/下一话 + 「N / M」；**读完自动续下一话**、跨话进度连续（重开停在原来那一话）；话内的 PDF / 漫画 / 音频各用对应阅读器；**末话读完接系列下一册** |

- **阅读器里的共同点**：进度自动回写（切后台/关页面也补发）；多设备读到别处会弹「跳过去」提示（**只有你点它才动你的位置**）。
- **漫画库里的 PDF**：默认按**漫画形态**读（逐页渲染成图，单/双页、右到左、无间隙全适用），工具栏可一键切回 PDF 视图；两边**共用页进度**。
- **自动续接的边界**：无系列信息、已是最后一册、或请求失败 → **只提示不跳转**（默认开，可在对应设置页关掉）。

## 5. 记录、批注与成长

- **进度与状态**：未读 / 在读 / 读完 / 搁置 / 弃读；起止日期；**轮次（重读）**：一轮 =「开始读 → 读完」。
- **评分与书评**：1–5 星 + 文字，看阅读记录。
- **批注**：选中正文高亮（4 种样式：高亮/下划线/删除线/纯笔记）、写想法；按书聚合、可检索、**可导出**（Markdown / JSON / CSV，可按书或按库收窄）。
  也支持从 **KOReader 导出文件导入**（靠位置锚定位，不再「搜第一段相同的话」）。
- **书签**：位置锚去重、点击跳回原处。
- **阅读日志**：按时间的阅读流水（每本书详情页也有「阅读日志」标签，含进度/时长双轴图）。
- **成就 / 通知**：基于阅读数据的成就墙；通知中心（后端合并同类型消息，顶栏显示 `×N`）。
- **阅读活动**：贡献热力图 + 时间轴。

## 6. 元数据与整理

- **编辑元数据**（详情页「编辑元数据」）：书名/作者/系列/序号/语言/出版社/标签/ISBN/副标题/提供商 ID 等；**所有格式都能改**；
  改动**只存应用数据库，绝不写回文件**；每个字段可「清空」（盖住在线值）或「恢复在线」（撤销覆盖）。
- **抓取元数据**（设置 → 书库 → 元数据）：14 家提供商（见 `docs/architecture.md` §8）；**一律先预览再应用**；
  字段级写入策略、字段级锁定、置信度阈值、题材黑名单、自定义字段；来源顺序可按书语种自动重排。
- **系列级元数据**（系列详情页）：简介 / 出版社 / 首发年 / 题材 / 册数；可编辑、可恢复在线、可「抓取全部系列」；
  还可**重排册号**（只改服务端记录，不动文件名与文件内容 ⇒ 进度/批注/评分/收藏不断链）。
- **改名与合并**（工具 → 实体管理）：作者/系列成批改名（实质是**移动文件**，同时写服务端元数据）、合并。
- **批量重命名**（工具）：按规则生成「旧名 → 新名」对照表（冲突行置灰），确认后才落盘。
- **刮削出版**：在建库时选**成品目录**，扫描入库后自动把元数据写进**副本**（硬链接，跨文件系统回退复制），
  供 Komga 等外部阅读器读取；**源文件一字节不改**。失败/待确认的书可在「工具 → 转换日志 → 刮削」里人工整理。

## 7. 统计与体检

- **数据统计**：书库分区（规模、入库节奏、Top 作者/系列/出版社/题材、年代分布、元数据完整度与评分分布、格式构成、存储占用…）
  与阅读分区（完成量、节律、时长、速度、时段、漏斗…）两块，共 **30 张图表**，窗口 7 / 28 / 90 天可切换。
- **书库体检**：缺作者 / 缺语言 / 无封面 / 零字节 / 解析失败。
- **缺失资源**（工具）：列出异常成品并逐条说明原因。

## 8. 工具（单页 + 顶部标签栏，9 个）

实体管理 / 批量重命名 / 重复书籍（同作者 + 书名相似度阈值可调）/ 缺失资源 / 书源管理 / 导出目录 / 本地导入 / 转换日志（含「日志」「刮削」两个子标签）/ 书库管理。

> **安全约定**：会改磁盘的三个工具（实体管理 / 批量重命名 / 重复书籍）一律**先预览、再应用**；
> 「删除」是**移入回收站**（`CONFIG_DIR/cache/recycle`），**从不直接删文件**。

## 10. 多端与外部软件

| 目标 | 怎么做 |
|---|---|
| 用别的阅读器读（OPDS） | 设置 → 设备 → OPDS：开启后用支持 OPDS 的 App 填地址；可**按库订阅**（`/opds/lib/<库 id>`） |
| 用 Komga 客户端读漫画/PDF | 设置 → 设备 → Komga：客户端地址填本应用即可（可冒充 Komga 服务端，逐页渲染漫画与 PDF） |
| KOReader 进度互通 | 设置 → 设备 → KOReader：按 kosync 协议双向同步进度 |
| 外部账号 | 设置 → 外部账号：Hardcover / Readwise 可存凭据并**真实验证连通性**；StoryGraph 无公开 API，如实标注不可验证 |

## 11. 常见问题

- **为什么我在 Calibre / SMB 里看不到我编辑的元数据？** 因为元数据只存应用数据库、**不写回文件**（这是刻意的）。
  经本应用 / Komga 接口 / OPDS / 连服务读都能看到。唯一写文件的是「刮削出版」，它写的是**副本**。
- **为什么删了书，文件还在？** 「删除」是移入**回收站**（`CONFIG_DIR/cache/recycle`），可人工取回；这是防误删的设计。
  第 75 期起删除的口径：**删一本书**会把同一本的**三份**拷贝各自移入回收站 —— 收书目录里的**本地原件**、
  书库里的文件、出版副本（三份里本来就没有的如实略过，不算失败）；**移除一个书库**只回收**项目内**的两份，
  收书目录里的**本地原件保留**。成品副本被删时，后台流程**只会提示待确认**，绝不自动删源。
- **为什么 PDF 出现在漫画库？** PDF 既可能是电子书也可能是扫描版漫画，**放哪个库由你决定**；放进漫画库就默认按漫画形态读。
- **为什么漫画库里的 43 个 `第1话…第43话` 变成了书架上的 1 本？** 那是**序号单元合并**：漫画库 / 有声书库里，
  一棵子树中有 ≥2 个能解析出序号的媒体文件（`第1话` / `第二话` / `第03话` / `4 第4话` / `01.pdf` 都算）时，
  整棵树按**一本合集**处理，书名会剥掉「（1-43话）」这类范围备注，话数显示成「N 话」，点进去逐话连读。
  看着不像连载的目录（一个文件夹里几本独立漫画）**不会**被合并；同一个目录放进**电子书库**也不会。
  ⚠️ 合并后是一本**新书**：旧的那几条的进度 / 评分 / 收藏**不会**并过来（旧记录仍留在库里，没有丢）。
- **为什么有些元数据来源标着「易失效」？** 那是页面抓取型提供商（站点改版就可能解析失败），如实标注而非隐藏。
- **打开书架会不会很慢？** 书目走**索引**（不扫盘），一次页面加载同一份数据只拉一次；响应还开了 gzip。
  若你的实例异常慢，先在「设置 → 服务端 → 审计日志」与「工具 → 转换日志」看是否有失败堆积。
