# 使用说明（user-guide）

> 面向**使用者**：每个功能是干什么的、在哪儿、怎么用、有哪些边界。
> 部署与配置见 `README.md`；原理见 `docs/architecture.md`；界面视觉规范见 `docs/DESIGN.md`。

## 1. 第一次进入

1. 浏览器打开 `http://<NAS-IP>:8992`（默认端口；部署细节见 `README.md`）。
2. 登录：字段是 **账号 + PIN**（默认 `admin` / `changeme`，请尽快在「设置 → 你 → 个人资料」改）。
3. 若还没有书库，会看到**首屏引导**：点「新增书库」打开**就地弹窗向导**（5 步：基本信息 → 来源 → 扫描 → 阅读 → 自动化）。
   - **来源**必须落在「来源根」之内（部署时的 `LIBRARY_SOURCE_DIR` 或其下的多根 `LIBRARY_SOURCE_DIRS1..N`）。
   - 也可以稍后在 **设置 → 书库 → 书库管理**（`#/settings/libraries`）里管理。
4. 建库后再点「立即扫描」，书就进书架了。

> 顶栏是**全站入口行**（仪表盘 / 探索发现 / 收书目录 / 数据统计 / 阅读记录 / 通知 / 成就 / 任务 / 工具 / 搜索 / 外观 / 用户菜单）；
> 左侧栏负责**浏览类**导航（实体总览 / 作者 / 系列 / 批注 + 库 / 智能书架 / 收藏夹 / 帮助）。
>
> **侧栏的四种操作**（第 90 期）：顶栏左上角的按钮或 **⌘/Ctrl+B** 开合侧栏；拖侧栏**右缘那条细边条**可调宽（224–480px，
> 轻点一下则是开合）；收起后是**只显示图标的窄条**（鼠标悬停出名称）。**窄窗口（≤640px）**下侧栏自动变成**抽屉**：
> 从左侧滑出、点一下导航项就收起，Esc 或点抽屉外面也能关。
> 折叠状态与宽度**记在本机**（换设备各用各的），不进账号同步。

## 2. 把书放进去（三条路）

| 方式 | 怎么做 | 结果 |
|---|---|---|
| **丢文件** | 把文件拷进部署目录的 `./input` | 自动收进书库并记日志（`.txt` **原样入库**，不再转换） |
| **界面导入** | 工具 → 本地导入：拖拽上传 / 按服务器路径入库；也可启停监听、立即扫描 | 同上 |
| **在线书源** | 探索发现：搜书名 → 结果可「预览」→「下载」；进度在任务中心 | 抓到正文 → 分章 → 组装 EPUB → 入库 |

支持形态：EPUB / PDF / TXT / FB2 / MOBI / AZW3…、漫画 CBZ / CBR、有声书（单文件或**一章一文件的目录**）。
`.cbr` 需要容器内有 `bsdtar`（官方镜像已含）；未安装时相关入口会明确提示。
**放进书库根目录**的还有第三种形态：漫画库 / 有声书库里的**序号单元树**（`《书名》/第1卷/第1话.pdf`…）
—— 一棵树会合成**一本书**、逐话连续读（见 §4）。⚠️ 走「收书目录」丢进来的目录**不做**这种合并。
同一类库里还有「**标题 + 尾部编号**」的写法（`超人前传0904.pdf`、`超人前传1408.pdf`）：
把这类散文件放进**一个子文件夹**（如 `超人前传/`），这个文件夹也会合成一本合集，
尾部编号就是话号（904、1408；前导零忽略）。两条边界：**平铺在库根目录**的散文件**不会**合并
（仍是各自一本）——想合并就放进一个子文件夹；同一个文件夹里出现**两种不同的标题前缀**
（`超人前传0904.pdf` 与 `另一部作品0905.pdf`）也**不**合并。

### 2.1 会不会在磁盘上多出一份文件？

取决于你怎么给 —— 两条路，差别只有「复制 / 不复制」：

| 给法 | 磁盘上 | 代价 |
|---|---|---|
| **投递**：往「收书目录」（部署目录的 `./input`）丢文件，或在界面里导入 / 从在线书源下载 | **会复制一份**进书库根 | 这份复制不是白占地方：应用的**命名规则**与 **Komga 布局**（系列目录、`第01卷`…）只能施加在副本上 —— 你的源文件**绝对只读** |
| **原地引用**：直接把书放进某个书库的**内容来源**文件夹 | **零复制**，书在原地被引用 | 文件名保持原样（应用不改你的源文件）；书籍在 NAS 上的位置就是它的位置 |

「内容来源」= 建库时选的那些文件夹，且必须落在部署配置的**来源根**（`LIBRARY_SOURCE_DIR` 或
`LIBRARY_SOURCE_DIRS1..N`）之内。所以**「从 NAS 拷进 `./input` 再导入」这一步确实会多出一份** ——
想避免就换个给法：把 NAS 上那个书库目录配成来源根，建库时直接引用它。

书的**元数据**（书名 / 作者 / 封面 / 刮削结果）与**阅读进度 / 批注 / 评分**都存在项目里，
与源文件放哪儿无关；原地引用不影响它们，也不影响按命名规则生成**出版副本**（那是独立输出，
见 §6）。

## 3. 找书与分类

- **书架**（顶栏「书架」）：网格 / 列表 / 表格三视图；搜索、排序、按系列折叠、多选批量（标记状态 / 评分 / 加入收藏夹）；
  首字母分桶跳转；书卡上有 ⋮ 菜单（阅读/收听、**在线阅读**、**检查更新**、快速预览、下载、
  添加到收藏、设置状态、编辑元数据、书籍详细信息、删除）—— 其中「阅读/收听」「在线阅读」
  「检查更新」「下载」都是**能用的才出现**，不摆点不动的假入口（可用性以服务端判定为准，见 §4.1）。
- **实体总览**（侧栏「浏览 → 实体总览」）：按**本地**元数据维度浏览（作者 / 系列 / 题材 / 出版社 / 语言 / 收藏六维）。
  ⚠️ 与「探索发现」不是一回事：那是**外部书源检索**。
- **智能书架**（侧栏）：自定义规则（字段 + 操作 + 值；全部满足 / 任一满足），规则存服务端、命中数实时预览。
- **收藏夹**（侧栏）：跨书归类，可新建 / 加书 / 移出 / 重命名。

## 4. 读书

| 阅读器 | 入口 | 主要设置 |
|---|---|---|
| **ePub / TXT** | 书卡或详情页「阅读」 | 排版增强：翻页/纵向/横向、分栏、字距词距、两端对齐、13 档主题、字体/字号/行高/宽度/边距/缩进；**滚动到底自动续下一章**（默认开）；**使用书内排版**（默认开，见下） |
| **PDF** | 同上（PDF 走 pdf.js） | 滚动模式（翻页/纵向/横向）、页展（单/双页奇右/偶右/自动）、适配（整页/宽度/自动/自定义）；**读完自动进下一册**（默认开） |
| **漫画（CBZ/CBR）** | 同上 | 模式（翻页/纵向/无间隙）、单双页、适配、方向（左→右 / 右→左）、页间距、背景、跨页对齐、宽页处理、小屏强制双页、**自动翻下一册**（默认开） |
| **有声书** | 书卡或详情页「收听」 | 倍速、快退/快进间隔、睡眠定时、轨列表；**同册内自动续下一轨**（内置）+ **跨册续接**（默认开） |
| **合集（话）** | 书卡或详情页「阅读」（漫画库 / 有声书库里的序号单元树，见 §2） | 左边话目录 + 上/下一话 + 「N / M」；**读完自动续下一话**、跨话进度连续（重开停在原来那一话）；话内的 PDF / 漫画 / 音频各用对应阅读器；**末话读完接系列下一册** |

- **阅读器里的共同点**：进度自动回写（切后台/关页面也补发）；多设备读到别处会弹「跳过去」提示（**只有你点它才动你的位置**）。
- **漫画库里的 PDF**：默认按**漫画形态**读（逐页渲染成图，单/双页、右到左、无间隙全适用），工具栏可一键切回 PDF 视图；两边**共用页进度**。
- **自动续接的边界**：无系列信息、已是最后一册、或请求失败 → **只提示不跳转**（默认开，可在对应设置页关掉）。
- **书内插图与书内排版**（第 76 期）：EPUB 里的插图、书自带的字体 / 缩进 / 图文混排，以及固定版式书的整页版式，
  都会照书原样呈现；书内样式**只作用在正文区**，不会影响阅读器工具栏与外壳。
  若某本书的排版看着不合适，可在阅读设置里关掉「**使用书内排版**」回到应用自己的排版口径
  （固定版式那类书必须开着 —— 整页版式就是靠它摆出来的，所以该开关对它们禁用）。

### 4.1 在线阅读（接你自己的书源，第 93 期）

本地还没有这本书、文件坏了读不了，或者你想读的是源站上最新的那一版时用它。

- **怎么绑**：打开书 → 详情页「**在线阅读**」卡 → 选一个书源（自动按书名去源站匹配，匹配不到可手动粘书页地址）
  → 绑完点「**开始在线读**」（书卡 ⋮ 菜单里也有「在线阅读」）。绑完就记住了，**看书卡 ⋮ 里有没有这一项**即可知道。
- **读到的是什么**：在**本项目自己的阅读器**里逐章读源站正文 —— 主题、字号、版式、翻页、目录
  和你读本地书时完全是同一套。源站的样式与脚本一律不带进来（正文以纯文本呈现）。
  页面顶部常驻一行「本页内容来自源站 X 的在线页面」，目录抽屉顶部同一条：**内容是谁的，始终看得见**。
- **换设备续读**：读完一章就把位置记在**服务端**。电脑上读到第 7 章，手机上打开就是第 7 章 ——
  不只是同一台机器的两个标签页。源站目录与本地章节对得上时，本地阅读进度也会一起更新。
- **断网还能读**：读过的章节缓存在本机（**只落缓存目录，不进书库、不动任何书文件**）。
  断网时横幅会如实改成「内容选自本机缓存（抓取于 …）」；缓存里也没有的那一章会明说取不到，不会白屏。
- **自动补齐本地**：本地读不了这本书时，在线**读过 5 章之后**会自动把它下载成本地副本 ——
  **还是书架上的那一条**（同一本书，进度 / 批注 / 绑定都不丢），不会凭空多出一本重名的书。
- **「检查更新」**：书卡 ⋮ 菜单与详情页在线读卡里都有。它去源站看有没有新章节，有就**追加**到本地副本末尾
  （已有章节一个字都不动 ⇒ 进度与批注不会错位），结果直接给一句报告（「新增 3 章」）。
  源站换了版本、目录与本地对不上时它**拒绝写入**并说明原因 —— 这时想要源站那一版，
  用卡下方的「**用源站整本覆盖本地**」（会二次确认，并告诉你代价：章节结构可能变，进度按章号重新对齐）。
- ⚠️ **这块要能用，得先在「设置 → 网络与下载」打开下载开关**（它同时管搜索 / 下载 / 预览 / 取目录 / 在线阅读，
  判据只有这一处）。关着时这一族入口一律不显示并如实说明原因。
- ⚠️ **在线读时没有书签 / 批注**：它们需要本地文本锚点，而线上正文与本地不是同一份文本。
  这两个入口在在线模式里会隐藏（不是灰掉的假按钮）。

## 5. 记录、批注与成长

- **进度与状态**：未读 / 在读 / 读完 / 搁置 / 弃读；起止日期；**轮次（重读）**：一轮 =「开始读 → 读完」。
- **评分与书评**：1–5 星 + 文字，看阅读记录。
- **批注**：选中正文高亮（4 种样式：高亮/下划线/删除线/纯笔记）、写想法；按书聚合、可检索、**可导出**（Markdown / JSON / CSV，可按书或按库收窄）。
  也支持从 **KOReader 导出文件导入**（靠位置锚定位，不再「搜第一段相同的话」）。
- **书签**：位置锚去重、点击跳回原处。
- **阅读日志**：按时间的阅读流水（每本书详情页也有「阅读日志」标签，含进度/时长双轴图）。
- **成就 / 通知**：基于阅读数据的成就墙；通知中心（后端合并同类型消息，顶栏显示 `×N`）。
- **阅读活动**：贡献热力图 + 时间轴。

## 6. 元数据与整理

- **编辑元数据**（详情页「编辑元数据」）：书名/作者/系列/序号/语言/出版社/标签/ISBN/副标题/提供商 ID 等；**所有格式都能改**；
  改动**只存应用数据库，绝不写回文件**；每个字段可「清空」（盖住在线值）或「恢复在线」（撤销覆盖）。
- **抓取元数据**（设置 → 书库 → 元数据）：14 家提供商（见 `docs/architecture.md` §8）；**一律先预览再应用**；
  字段级写入策略、字段级锁定、置信度阈值、题材黑名单、自定义字段；来源顺序可按书语种自动重排。
- **系列级元数据**（系列详情页）：简介 / 出版社 / 首发年 / 题材 / 册数；可编辑、可恢复在线、可「抓取全部系列」；
  还可**重排册号**（只改服务端记录，不动文件名与文件内容 ⇒ 进度/批注/评分/收藏不断链）。
- **改名与合并**（工具 → 实体管理）：作者/系列成批改名（实质是**移动文件**，同时写服务端元数据）、合并。
- **批量重命名**（工具）：按规则生成「旧名 → 新名」对照表（冲突行置灰），确认后才落盘。
- **刮削出版**：在建库时选**成品目录**，扫描入库后自动把元数据写进**副本**（硬链接，跨文件系统回退复制），
  供 Komga 等外部阅读器读取；**源文件一字节不改**。失败/待确认的书可在「工具 → 转换日志 → 刮削」里人工整理。

## 7. 统计与体检

- **数据统计**：书库分区（规模、入库节奏、Top 作者/系列/出版社/题材、年代分布、元数据完整度与评分分布、格式构成、存储占用…）
  与阅读分区（完成量、节律、时长、速度、时段、漏斗…）两块，共 **30 张图表**，窗口 7 / 28 / 90 天可切换。
- **书库体检**：缺作者 / 缺语言 / 无封面 / 零字节 / 解析失败。
- **缺失资源**（工具）：列出异常成品并逐条说明原因。

## 8. 工具（单页 + 顶部标签栏，9 个）

实体管理 / 批量重命名 / 重复书籍（同作者 + 书名相似度阈值可调）/ 缺失资源 / 书源管理 / 导出目录 / 本地导入 / 转换日志（含「日志」「刮削」两个子标签）/ 书库管理。

> **安全约定**：会改磁盘的三个工具（实体管理 / 批量重命名 / 重复书籍）一律**先预览、再应用**；
> 「删除」是**移入回收站**（`CONFIG_DIR/cache/recycle`），**从不直接删文件**。

## 9. 设置（36 页 / 6 组，路由 `#/settings/<组>/<页>`）

| 组 | 页 |
|---|---|
| **你**（12） | 个人资料 · 主题 · 封面样式 · 布局 · 浏览行为 · 电子书 · PDF · 漫画 · 有声书 · 阅读字体 · 阅读通用 · 通知 |
| **书库**（10） | 书库管理 · 元数据来源 · 字段规则 · 自定义字段 · 置信度评分 · 书籍自动抓取 · 作者元数据 · 题材黑名单 · 文件命名 · 维护 |
| **设备**（3） | OPDS · KOReader · Komga |
| **外部账号**（3） | Hardcover · Readwise · StoryGraph |
| **服务端**（3） | 收书目录 · 服务端字体 · 审计日志 |
| **本项目扩展**（5） | 转换 · 监听 · 网络与下载 · 高级 · 关于 |

- 设置页侧栏支持**搜索**；有未保存改动时会提示。若某页写着「未支持」，那是**如实标注**（本项目不造只动不响的控件）。
- **更新（设置 → 扩展 → 更新）**：默认只检查并提示新版本。要应用内「立即更新」或自动更新，需在
  `docker-compose.yml` 的 `volumes` 下取消注释 `/var/run/docker.sock` 那一行（默认不挂载，把宿主 docker
  控制权交给容器仅在信任环境启用）；未挂载时页内状态卡会如实说明原因并降级为「复制升级命令」。开启自动更新后：
  容器**每次启动即校验一次版本**；发现新版会**先自动备份业务数据**（PostgreSQL 走 dump、SQLite 整文件拷贝，
  落 `config/backups`，保留最近 5 份；**备份失败即中止本次更新**）再拉镜像重建自身；**失败按 1 小时 → 6 小时 →
  24 小时退避重试**（不会失败一次就永久放弃），失败原因与下次重试时间会显示在更新页与「新功能」页。

## 11. 常见问题

- **为什么我在 Calibre / SMB 里看不到我编辑的元数据？** 因为元数据只存应用数据库、**不写回文件**（这是刻意的）。
  经本应用 / Komga 接口 / OPDS / 连服务读都能看到。唯一写文件的是「刮削出版」，它写的是**副本**。
- **为什么删了书，文件还在？** 「删除」是移入**回收站**（`CONFIG_DIR/cache/recycle`），可人工取回；这是防误删的设计。
  **删一本书**会把同一本的**三份**拷贝各自移入回收站 —— 收书目录里的**本地原件**、书库里的文件、出版副本
  （三份里本来就没有的如实略过，不算失败）。**移除一个书库**第 81 期起**默认只删登记、一个磁盘文件都不动**；
  要连文件一起清，需在确认框里勾选「连文件一起清理」（回收的是项目内的两份，收书目录里的**本地原件保留**），
  受理后到「任务中心」看进度。成品副本被删时，后台流程**只会提示待确认**，绝不自动删源。
- **误删 / 误搬了怎么办？** 「设置 → 维护 → 回收站还原」可把回收站里的文件**按原路径搬回**：
  支持逐条或全部还原，目标已存在时**退让改名**（`名字 (2).ext`）绝不覆盖；重复操作只会跳过已还原的。
  第 81 期之前回收的文件没有台账，走「指定目标目录」的孤儿还原。
- **为什么 PDF 出现在漫画库？** PDF 既可能是电子书也可能是扫描版漫画，**放哪个库由你决定**；放进漫画库就默认按漫画形态读。
- **为什么漫画库里的 43 个 `第1话…第43话` 变成了书架上的 1 本？** 那是**序号单元合并**：漫画库 / 有声书库里，
  一棵子树中有 ≥2 个能解析出序号的媒体文件（`第1话` / `第二话` / `第03话` / `4 第4话` / `01.pdf` 都算）时，
  整棵树按**一本合集**处理，书名会剥掉「（1-43话）」这类范围备注，话数显示成「N 话」，点进去逐话连读。
  看着不像连载的目录（一个文件夹里几本独立漫画）**不会**被合并；同一个目录放进**电子书库**也不会。
  ⚠️ 合并后是一本**新书**：旧的那几条的进度 / 评分 / 收藏**不会**并过来（旧记录仍留在库里，没有丢）。
- **`超人前传0904.pdf` / `超人前传1408.pdf` 这类能不能也合成一本？** 能，前提是三条都满足：
  ① 它们在**同一个子文件夹**里（**平铺在库根目录的散文件不合并** —— 把它们放进一个子文件夹即可）；
  ② 文件名是「**标题 + 尾部编号**」且编号**紧贴**标题（`超人前传-0904` / `超人前传 0904` 这类夹了分隔符的**不算**）；
  ③ 同一文件夹里的**前缀（标题）一致** —— 出现两种前缀（`超人前传0904.pdf` 与 `另一部作品0905.pdf`）
  **不合并**（宁可少合并，也不把两部作品粘成一本）。`vol.1.cbz` 这类「第 N 卷」写法同样不算话号。
  合并后与上面的序号单元完全同构：书架 1 条、话数 = 文件数、详情里按**序号**排序、逐话连读。
- **为什么有些元数据来源标着「易失效」？** 那是页面抓取型提供商（站点改版就可能解析失败），如实标注而非隐藏。
- **打开书架会不会很慢？** 书目走**索引**（不扫盘），一次页面加载同一份数据只拉一次；响应还开了 gzip。
  若你的实例异常慢，先在「设置 → 服务端 → 审计日志」与「工具 → 转换日志」看是否有失败堆积。
- **「在线阅读」/「检查更新」为什么有时不出现？** 这两个入口都是**能用的才出现**，不摆点不动的假按钮。
  常见原因：① **下载开关关着**（「设置 → 网络与下载」；它同时管搜索 / 下载 / 预览 / 取目录 / 在线阅读）；
  ② 这本书**既没有书源留档、也没有绑定书源**（那就先去绑一个源，或从书源下载它）；
  ③ 「在线阅读」还要求这个源**支持逐章取正文**。具体原因写在详情页「在线阅读」卡里（逐字来自服务端）。
- **在线阅读会不会动我的书文件？** 章节缓存**只落缓存目录**（不进书库、不碰任何书文件）；
  只有「读满 5 章自动补齐」和「检查更新 / 整本覆盖」这几条**由你触发或由阅读行为触发**的路径会写本地，
  而且都是写**这本书自己的位置**（同一个 `book_id`，不会多出一本重名的书）。
  默认那条路只**追加**新章，既有章节一个字都不动；整本重写只在你显式点「用源站整本覆盖本地」时发生。
