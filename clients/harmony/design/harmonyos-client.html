书斋 — 鸿蒙端样式稿

纯瘦客户端（书在 NAS、进度在 NAS、端内只存 baseUrl token deviceId）。 颜色圆角阴影全部取自仓库真值源 tokens.css，阅读面按 R1 路线做成“ArkWeb 载入现有 SPA”的观感。

tokens.css 同值 radius 0.625rem 暖中性 tint-h 80 零外部依赖

照抄的部分

  • 语义 token 不硬编码：卡片、边框、阴影全走 --card / --border / --elevation-*，切暗色只换一层变量。
  • 暖中性底：--tint-h:80，所以灰面偏米，不像通用后台的冷灰。
  • 大标题用衬线：书架 / 详情 / 浮层标题走 --font-serif，与正文无衬线分层。
  • 格式胶囊用固定色：EPUB 绿 / TXT 灰褐 / PDF 红，色相不跟 accent 漂移。
  • 行+标签+控件：设置页完全是 BookOrbit 的设置范式。

为鸿蒙端做的取舍

  • 切库走真接口：GET /api/libraries 给库清单；/api/books 没有 library_id，端上取全量后按 library_id 本地过滤（与网页端同一口径）。
  • 移书是四步：targets（搬不进去的库置灰并原样显示原因）→ preflight（逐本理由）→ plan（混进一本不相容就整批 400）→ apply（后台真搬，轮询 /api/tasks/{tid}）。
  • 同步是拉取，不是推送：后端无 WebSocket / SSE（apply 注释写明「不引入 SSE」）。端上动作立刻 POST，之后靠 /api/libraries/scan-state + 任务行轮询 + 下拉刷新。
  • 已开始读的书落本地：判定只一条 —— 有进度（percent > 0）就缓存整本章节 HTML 与目录，断网照读；没缓存的书断网如实报错，绝不给空书架。
  • 章节不自造编号：右侧灰字直接是服务端的 spine index（章节接口的入参），没有“第 N 章”的第二次实现。
  • 进度条只有一条真值：数字来自 GET /progress，不本地推算。
  • 断网就如实报错：不给空书架、不给假进度（AGENTS §1 不做假数据）。
  • 版本门禁：连之前先打 /health 比版本，过旧只提示不硬拦。

右侧开关可以切外壳明暗、模拟断网、模拟服务端过旧 —— 三个最容易在评审时被问到的状态。

评审时先看这四处

  • 阅读面：正文是宋体 + 首字下沉，纸/夜/护三档；这层在真机上由 ArkWeb 载入现有 SPA，端上不复刻排版。
  • 书架：封面是 CSS 渐变+竖排书名（不是图片），进度细线来自服务端 percent。
  • 详情：章节按卷分组，右侧灰字是 spine index；当前章用朱砂底标记。
  • 断网态：整屏说明原因，而不是留一个空书架 —— 这是「不做假数据」在 UI 上的样子。
