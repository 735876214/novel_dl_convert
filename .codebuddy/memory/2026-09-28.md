### 做了什么（核心：三份拷贝 → 一份真值源）
- 新建 **`frontend/src/lib/seriesNext.ts`**（唯一真值源）：
  - `SERIES_NEXT_MSG`：三条文案（统一「册」）：无系列 / 已是末册 / 请求失败；
  - `resolveNextVolume(series, bookId, fetchSeries?)`：**纯函数**，返回 `{next, reason: ok|no_series|last|error, message?}`，
    异常内部收敛为 `error`、**绝不外抛**；`fetchSeries` 可注入 ⇒ 单测完全离线；
  - `useSeriesNext().goToNextVolume({enabled, series, bookId, routeBase, beforeJump})`：`enabled` 门（关着**静默返回、不弹提示**）→ 解析 → 因因弹提示（**同类 2s 节流**、跨因立即放行）→ 命中先 `beforeJump` 再 `router.push`；模块级**单飞闸**。
- **三处接入**：`ComicReader.vue` / `PdfReader.vue`（`routeBase:'/read'`，`beforeJump: save`）/ `AudioPlayer.vue`（`routeBase:'/listen'`）。
  删掉三份重复实现与各自的 `autoNextBusy`；⚠️ 触底闩 `autoNextArmed` **留在组件**（滚动渲染态）。

### 踩坑 / 经验
- **playwright 注入 token 不稳**：`localstorage-set nf_token` + 重载仍停在登录门禁 ⇒ 改用**登录表单**填 `admin/changeme` 点「进入」即通（已写入 REF）。
- 隔离实例启动：`Start-Process` 的 `-RedirectStandardOutput` **要求目标目录已存在**，否则进程起不来且无日志（先 `New-Item` 建目录）。
- 关掉测量口径：`aria-checked` 在点击后的**同一 tick 读不到新值**（Vue 未重渲染），但 `localStorage` 已写 ⇒ 以「刷新后仍为关」为准。
