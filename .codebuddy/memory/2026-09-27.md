## 第 61 期（进行中）· 8 项：漫画库 PDF / 通知合并 / 打开提速 / 自动续接 / 目录 / 滚轮翻页 / 翻页右溢 / 进度实时

用户拍板的范围：PDF 要「还能按漫画形态读」；自动续接选 A+C+D（滚动无缝续章 / PDF·漫画进下一册 / 有声书接下一轨，**翻页模式预取不做**）；通知只做后端合并 + 顶栏角标与通知中心（同类型 = 同 action + 状态类别 + 同一主体）；目录问题是 EPUB 点击不跳/跳错。

### 已完成并真机实测
1. **翻页右溢**：根因是位移步长用「容器宽+栏距」，而真实栏距是「栏宽+栏距」，且正文宽度与内边距口径叠加错了一层（我先修错一次：把 width 设成可用宽，内容盒反而又窄掉两个内边距）。现在 width=整屏宽（border-box 含内边距）、栏宽=可用宽/栏数、步长=栏宽+栏距 —— 实测步长 938 = 栏宽 906 + 栏距 32，每格滚轮恰好一页，截图右缘无残影。
2. **滚轮翻页**：翻页模式加 non-passive wheel 监听（累计阈值 24px + 220ms 时间锁），实测双向；滚动模式不抢滚轮。
3. **目录**：改为按 `flat` **位置**跳转（`tocView` 逐项带 pos）；加**请求序号守卫**（连点时慢响应后到会覆盖后跳的那一章 = 「跳错位置」真因之一）；加「加载章节…」提示（实测 0.4s 可见，解决「点了没反应」的观感）；无章节序号的条目不再渲染成死项。
4. **进度实时**：新增 `library.patchProgress` 就地回写 store（EPUB/PDF/漫画/音频四个阅读器都调），切后台与关页面时补发（复用会话的 visibilitychange + 新增 pagehide）；首页「继续阅读」书架行加进度条与百分比 —— 实测 SPA 内切仪表盘即显示 10%，无需重拉整库。
5. **漫画库 PDF**：`library._COMIC_EXTS` 纳入 .pdf；ComicReader 新增 `source='pdf'`（pdf.js 逐页渲染成 blob 图，交回**同一套 `<img>` 漫画布局** → 单/双页、右到左、无间隙连续全部适用）；`comicPrefs.pdfMode` 决定默认阅读器，两个阅读器互有切换入口并共用页进度 —— 实测双页下渲染出 2 张 900×1273 页图、往返切换保留页码。

### 踩坑（通用，值得记）
- playwright-cli 沙箱里 **没有 `setTimeout`**，且 `page.route` 一注册就报 `setTimeout is not defined` → 竞态类验证改由 vitest 钉（更可复现）。
- 该外壳下 `getByRole` 常匹配不到按钮（第 60 期教训已记）：用 DOM 文本点击。
- 自动化点面板按钮要先**自己维护「面板是否已开」**状态（按 DOM 猜会猜错：外壳里也有 `<aside>`）。
- 修 CSS 多栏位移类 bug：宽度是 **border-box**，「可用宽」要先扣内边距，两者混用会差出两倍内边距。
