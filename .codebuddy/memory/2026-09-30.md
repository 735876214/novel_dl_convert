## 二、后端改动

### 1. 回收台账（`db` + 三处移入点）

- 新表 `recycle_items`：`id / orig_path / recycled_name / why / size / created_at` + `idx_recycle_name`。
  ⚠️ **刻意不含 `book_id`** —— 它记的是「磁盘上某个被移走的路径」而非「某本书的数据」，
  改名 / 换库都不会让它失效 ⇒ **不进** `ORPHAN_TABLES` / `REMAP_TABLES` / `REMAP_PROBE_FILTER` / `REMAP_EXPLICIT_TABLES`
  （契约测试钉住）。
- 新增 `recycle_add` 与**永不外抛**的 `recycle_note`（文件已经移走了，不能因为记不上账把回收算失败），
  以及 `recycle_list` / `recycle_get` / `recycle_delete` / `recycle_clear`。
- 三个移入点接线：`publish.recycle`、`fileops.recycle_items`、`bookdock.remove`。
  ⚠️ `size` 必须在 `shutil.move` **之前**取（移走后原地就没了）；目录型条目用 `fileops.size_of` 递归和
  （win32 目录 `st_size` 恒 0，不能直接读）。

### 2. 长文件名加固（唯一实现 `fileops.recycled_name`）

- `RECYCLE_NAME_MAX = 255`；`trunc_bytes` 按 **UTF-8 字节边界**截断（不切坏多字节字符）；
  `recycled_name(name, stamp, n=0)` = `{stamp}_{n_}{name}`，超长时截断正文 + 追加 `~<8 位短哈希>`（保唯一可辨）
  + 尽量保住扩展名。
- **三个调用方同批收敛**（原先各写了一份 `f"{stamp}_{name}"` / `f"{stamp}_{n}_{name}"`）。

### 3. 新增 `core/recycle.py`（台账读 + 还原）

`strip_stamp`（剥 `YYYYMMDD-HHMMSS_[n_]`）/ `free_path`（退让命名，思路同 `publish.free_rel`，
**自己实现以免 publish ↔ recycle 循环 import**）/ `restore_one`（`restored|renamed|missing|failed`）/
`_safe_name`（挡 `/`、`\`、`..`）/ `plan_restore` / `restore_many`（成功后 `db.recycle_delete` ⇒ 幂等可续跑，
逐项写活动日志，`on_row` 报进度）/ `list_items`（台账 + 磁盘实况 + 无台账孤儿，计数始终全量）。

### 4. `server.py`

- `api_delete_library` 转 `async def`、**删掉 `force`**、改 `purge_files`：
  默认只删登记、同步立即返回（`{purge_files:false, targets:0, task_id:null}`）；
  `purge_files=1` 时 `_purge_paths` **先物化 ②③ 清单**（必须在删登记与 `scrape_delete_by_library` 之前 —— ③ 依赖 `link_rel`），
  再 `db.task_create("librarypurge", …)` + `asyncio.create_task(_run_library_purge)`。
- 新端点：`GET /api/recycle`、`POST /api/recycle/restore`（+ `_recycle_on_row` / `_run_recycle_restore`，任务类型 `recycle`）。
  两个后台任务都**刻意不写 `result`**（有它前端会渲染成「下载」按钮）。
- `api_clear_recycle` 同批 `db.recycle_clear()`（文件都真删了，台账再宣称「可以还原」就是骗人）。
- 长操作在跑标记 `_ops_pending` / `_ops_idle` + `wait_background_ops()`；`tests/conftest.py::_quiesce_background`
  增加该调用（与 scrape / watcher / embed-refresh 同一条「测试不养旁路线程」纪律）。

## 五、踩坑（两条值得记住）

1. ⚠️ **回收目录是会话级共享的**：`fileops.recycle_dir()` 基于 `config.CACHE_DIR`，而 `isolated` 夹具**不切**它
   ⇒ 测试里断言「默认删库没掉文件 / 没产生回收件」**只能做名字差集**（前后各拍一次快照）。
   断言「目录里本来没有同名文件」会依赖用例执行顺序 —— 先在 `test_api_smoke`、后在 `test_library_purge` 上各假失败一次。
2. ⚠️ **`api_delete_library` 转 `async def` 会让契约测试的形状正则失效**：`tests/test_no_defaults_contract.py`
   原先匹配 `\ndef <fn>\(`，必须放宽到 `\n(?:async )?def`（lookahead 也要带 `async def`）。
