### 迁移的三个关键技术发现
1. **`bridge.css` 是前提拼图**。BookOrbit 的 `client/src/assets/theme/` 有 5 个文件，
   我们之前只拷了 4 个（tokens/accents/radius/fonts），**缺的 `bridge.css` 是 Tailwind v4 的
   `@theme inline` 桥接层**（映射 50 色 + 6 圆角 + 3 字体 + 6 阴影）。
   没有它，BookOrbit 的 `.vue` 里 `bg-card` / `text-muted-foreground` / `rounded-lg` / `shadow-sm`
   **根本生成不出来** —— 这是换 Tailwind 的核心动因。已补齐并验证：
   产物 CSS 里 `text-muted-foreground{color:var(--muted-foreground)}`，且未生成 `--color-muted-foreground`
   变量 → 确认是 `inline` 语义（运行时切主题无需重新生成工具类）。
2. **`@custom-variant dark (&:is(.dark *));` 必须声明**。Tailwind v4 的 `dark:` 默认跟随
   `prefers-color-scheme`，而本项目深浅色由 `<html class="dark">` 驱动。少了这行，
   **所有 `dark:` 工具类都不生效**。已从 BookOrbit main.css 照搬。
3. **执行 `@import` 顺序**：fonts → tailwindcss → theme 五件 → app.css。`app.css` 放最后，
   确保它的元素级规则（body 字号 14px、svg 尺寸）**覆盖 Tailwind preflight**。
   实测：preflight 给 `svg` 加 `display:block` 并未破坏观感（外壳与 v2 基线逐像素一致）。

## 宿主机安装 Python 3.12.10（完成）

  **最后一个带 Windows amd64 安装包的是 3.12.10**。npmmirror 的 `-/binary/python/` 也只镜像源码
  tarball，**Windows 安装包只能走 python.org**（实测 `https://www.python.org/ftp/python/` 返回 200 可达）。
- **安装方式**：下载 `python-3.12.10-amd64.exe`（25.7MB）后静默安装，走**用户级**、免管理员：

  Start-Process python-3.12.10-amd64.exe -Wait -PassThru -ArgumentList @("/quiet","InstallAllUsers=0",
    "TargetDir=C:\Users\qingr\python312","PrependPath=1","Include_pip=1","Include_launcher=1",
